# SAP ABAP on HANA

## Course Overview
SAP ABAP on HANA training covers modern ABAP programming tailored for the SAP HANA database and S/4HANA enterprise platform. Learners master database programming, Code-to-Data paradigm, SQL Script, AMDP, CDS Views, and performance optimization.

## Course Description
Comprehensive 25-module technical program covering the entire spectrum of SAP development: R/3 architecture, data dictionary, internal tables, Open SQL, selection screens, classical/interactive reporting, module pool dialog programming, ABAP Objects (OOP), ALV grid, file handling, BDC/data migration, Smart Forms, Adobe Forms, user exits, enhancement framework, TMS, SAP HANA architecture, HANA Studio/Eclipse, code pushdown, AMDP, OData/Gateway, CDS views, and ABAP 7.4/7.5 new syntax.
