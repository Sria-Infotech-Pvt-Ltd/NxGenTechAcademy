# SAP MM (Materials Management)

## Course Overview
Master procurement, inventory management, vendor evaluation, MRP, invoice verification, physical inventory, and S/4HANA Sourcing & Procurement.

## Course Description
Comprehensive 19-module functional procurement curriculum covering organizational structure, master data (material master, vendor master, info records, source list), Procure-to-Pay (P2P), inventory management, pricing procedures, release strategies, MRP planning, physical inventory, multi-module integration (FI, CO, SD, PP, WM), batch management, vendor evaluation, contracts, Logistics Invoice Verification (LIV three-way matching), SCM/SRM integration, and S/4HANA Sourcing innovations with Fiori apps.
