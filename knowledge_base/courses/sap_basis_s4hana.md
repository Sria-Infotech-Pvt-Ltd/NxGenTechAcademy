# SAP BASIS S/4HANA Training

## Course Overview
Master core SAP infrastructure administration, system installations, kernel upgrades, client administration, Transport Management System (TMS), user authorizations, HANA database administration, and backup/recovery.

Practical, hands-on administration training designed to make learners proficient in managing enterprise 3-tier SAP S/4HANA landscapes. Covers client operations, authorizations, role management, TMS transport routes, performance tuning, database backup/recovery, and SUM/DMO migration concepts.
