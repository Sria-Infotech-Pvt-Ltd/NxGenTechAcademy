# SAP BTP For Working Professionals

## Course Overview
Comprehensive SAP BTP module tailored for experienced working professionals. Master Cloud Application Programming Model (CAP), Cloud Foundry runtime, SAP HANA Cloud, Destination services, Cloud Connector, XSUAA security, and CI/CD lifecycle management.

## Course Description
Deep-dive enterprise cloud architecture program designed for working SAP consultants (ABAP/functional), Java/Node.js developers, and cloud engineers. Covers side-by-side extension development, Event Mesh messaging, SAP AI Core, SAP Build Process Automation, IAS/IPS identity provisioning, MTA deployments, and enterprise CI/CD release pipelines.
