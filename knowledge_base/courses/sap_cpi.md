# SAP CPI Training

## Course Overview
Master enterprise application integration using SAP Integration Suite / SAP Cloud Integration (CPI). Learn end-to-end integration flows (iFlows), standard adapters (SOAP, REST, OData, SFTP, IDoc, Mail), message mapping, Groovy scripting, content modifiers, and hybrid connectivity.

## Course Description
In-depth 17-module integration curriculum covering SAP BTP architecture, cloud middleware concepts, iFlow design patterns (request-reply, multicast, content enricher, splitter/gather), Groovy scripting, error handling subprocesses, security (TLS, MLS, OAuth, certificates), adapters (OData, SOAP, SFTP, IDoc, RFC, Ariba, SuccessFactors), SAP API Management, Integration Advisor, Open Connectors, Event Mesh, and Apache Kafka.
