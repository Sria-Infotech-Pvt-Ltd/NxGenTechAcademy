# SAP Fiori & UI5

## Course Overview
Learn modern SAP UX/UI design and development using SAPUI5, SAP Fiori design guidelines, SAP Business Application Studio (BAS), Fiori Launchpad configuration, and Fiori Elements.

## Course Description
Comprehensive 20-module front-end development program for the SAP ecosystem. Covers MVC architecture, JSON and OData models, two-way data binding, custom and standard UI controls, formatters, OData CRUD operations, batch requests, routing and navigation, Chrome Developer Tools and UI5 Inspector debugging, Fiori Launchpad tile configuration, Fiori Elements (List Reports, Object Pages, Overview Pages), responsive design (CSS Grid/Flexbox), QUnit automated testing, mobile app development, UI Theme Designer, and enterprise deployment.
